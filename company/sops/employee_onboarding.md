# New employee onboarding

## Information needed before starting

You need all five of these:
- full name
- department (Sales, Engineering, Finance, HR, Marketing or Operations)
- job title
- start date
- manager

If **any** of them is missing from the request, ask a human for the missing details
**before creating anything**. A half-created employee is worse than a short delay.

## Step 1: Create the employee record

Go to **Employees → New Employee** and enter:
- **Full Name:** as given.
- **Email:** `firstname.lastname@acme.com`, all lowercase (e.g. `jane.doe@acme.com`).
- **Department** and **Title:** as given.
- **Manager:** must be an existing employee; pick them from the list.
- **Start Date:** an actual calendar date (YYYY-MM-DD). Resolve relative dates such as
  "this Monday" or "next week" against today's date.

Note the new employee ID from the confirmation page.

## Step 2: Assign a laptop

- **Sales** and **Engineering** get a **MacBook Pro 14**.
- Everyone else gets a **MacBook Air**.

Go to **Equipment**, pick an asset of the right model whose status is **Available**
(never one that is In Repair or already Assigned), open its page and assign it to
the new employee. Assign exactly one laptop.

- **IT-7:** equipment worth more than **$2,000** needs IT manager approval.

## Step 3: Request system access

Go to **Access Requests → New Access Request** and submit one request per system:
- **Everyone:** Email, standard.
- **Sales:** CRM, standard.
- **People managers** (titles containing "Manager" or "Head of"): CRM, **admin** instead
  of standard. **SEC-1:** admin access needs security approval.
- **Never** request Finance Portal access for a new hire (**SEC-2**). Finance sets that
  up separately.

## Done when

- the employee record exists with the correct email, department, title, manager and
  start date (employee ID noted),
- exactly one laptop of the right model is assigned to them (asset tag noted), and
- every required access request has been submitted (request numbers noted).
